E-Commerce Sales Analysis Dashboard | Microsoft Excel

Project Overview
This project presents an interactive E-Commerce Sales Dashboard developed using Microsoft Excel to analyze business sales performance and profitability.

The dashboard provides insights into sales trends, customer segments, regional performance, product categories, and order distribution through interactive filters and visualizations.

Key Performance Indicators (KPIs)
- **Total Sales:** $2,64,74,659
- **Total Profit:** $24,95,874
- **Total Order Quantity:** 2,84,209
- **Average Profit Margin:** 10.86%

Dashboard Features

1. Sales Performance
- Monthly Sales Trend
- Total Sales and Profit Analysis
- Total Order Quantity
- Average Profit Margin

2. Regional Analysis
- Sales by Market Region
- Top 10 Countries by Sales

3. Customer Analysis
- Sales by Customer Segment
- Consumer, Corporate, and Home Office comparison

4. Product Category Analysis
- Top 5 Categories by Sales
- Bottom 5 Categories by Sales

5. Interactive Filters
- Order Date Timeline
- Customer Segment
- Shipping Mode
- Order Status

Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
- Data Analysis

Key Insights
- Consumer segment contributes the highest sales among the three customer segments.
- Europe and LATAM are among the leading market regions by sales.
- The United States leads the country-wise sales comparison.
- Cardio Equipment is the highest-performing category among the top five categories shown.
- The overall profit margin is 10.86%.

Project Objective
The objective of this project is to transform raw e-commerce sales data into an interactive dashboard that helps understand business performance and supports data-driven decision-making.
